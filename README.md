# Games-Dashboard
🎮 Global Video Game Sales Dashboard (1977–2024)
📊 Overview

This project analyzes global video game sales from 1977 to 2024, uncovering insights about regional trends, top-selling games, consoles, and genres using Tableau and Python (Pandas + Plotly).

The focus of this project is an interactive and visually rich dashboard that allows users to explore how gaming has evolved over the decades — across platforms, genres, and global markets.

🧠 Objective

Analyze the video game market trends across regions.

Identify the top-performing games, consoles, and genres.

Build an interactive dashboard to visualize insights dynamically.

Derive regional sales patterns and market share comparisons.

1️⃣ Data Cleaning & Preprocessing(Python)

Converted sales columns to numeric values
Removed nulls and invalid records
Standardized console and genre names
Mapped console codes to full names (e.g., “PS2” → “PlayStation 2”)

2️⃣ Data Exploration (SQL)

Calculated regional totals (NA, JP, PAL, Other)
Found top 10 games by total sales
Computed genre-wise and console-wise performance
Analyzed average critic scores per console

3️⃣ Dashboard Development (Tableau)

Built an interactive Gaming Sales Dashboard featuring:

🔸 Dashboard Sections

Global Sales Overview: Total sales per region with KPIs & bar charts

Top 15 Games: Horizontal bar showing top-selling titles with total units sold

Top 10 Consoles: Visual ranking of gaming platforms with total and average sales

Genre Performance: Pie/Donut charts showing market share by genre

Regional Market Trends: Stacked bar & map visuals for continental distribution

Critic Score vs. Sales Correlation: Scatter plot comparing quality vs popularity
